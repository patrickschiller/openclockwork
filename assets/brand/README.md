# OpenClockwork brand mark

`openclockwork-mark.svg` is the canonical, scalable source for the OpenClockwork
logo. It is based on the approved clock-and-location-pin concept and is designed
to remain recognizable from a 32 px app-bar icon up to large website artwork.

## Usage

- Use the SVG for websites, documentation, and interface chrome.
- Use `openclockwork-mark.png` only where SVG is unsupported.
- Pair the mark with the written name `OpenClockwork` in accessible HTML instead
  of baking the wordmark into a bitmap.
- Keep clear space around the mark equal to at least one clock-hand width.
- Do not add a background, rotate the mark, or recolor individual parts.

## Palette

| Role         | Color     |
| ------------ | --------- |
| Primary blue | `#0755AD` |
| Deep blue    | `#003D88` |
| Turquoise    | `#00C7C7` |
| Coral accent | `#FF5B4F` |
| Clock face   | `#FFFFFF` |

The PWA and Apple-touch exports use a deep-blue square background so the same
files are safe for operating-system icon masks.
